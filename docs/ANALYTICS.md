# Synthetic case analytics

The case analytics endpoint uses the latest confirmed import for each selected file. With no file selections it uses all confirmed case files. It reads accepted records only, retaining and flagging all duplicate candidates. Source links identify the original file, logical row and import version. Quarantined counts describe entire selected files, before query filters, because excluded timestamps may not be interpretable.

Time windows use offset-aware ISO timestamps, converted to UTC. The end is exclusive. Night activity defaults to 22:00–06:00 UTC; the API can change both hours. Duration is the sum or arithmetic mean of accepted CDR durations in seconds. Incoming and outgoing count callee and caller matches, respectively, for the exact selected subject; a self-call counts in both. No direction is inferred without a subject and confirmed mapping. Common contacts are the intersection of counterpart identifiers across every selected CDR file for a subject. Graph links are directed pairs with row counts and references; NetworkX computes node degrees. IPDR rows are shown as sessions without subscriber attribution; applying a subject filter excludes them because this import schema has no subscriber field.

The implementation does not yet support historical evidence-version selection, tower/device fields, IP/port interval correlation, local timezone night definitions, unusual-activity rules or coverage-qualified negative claims. It does not infer intent, identity, criminality or application usage. Computed results depend on officer-confirmed column mappings.
