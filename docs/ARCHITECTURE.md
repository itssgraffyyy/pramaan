# Architecture

The React dashboard calls a synthetic-only FastAPI service through the Vite development proxy. The temporary SQLite adapter stores cases, original file bytes, mappings, versioned output and transformation ledgers in `data/pramaan.sqlite3`. SQL triggers prevent updates and deletes through normal database operations, but an operator with filesystem/database access can alter them. The independent reconciliation endpoint re-reads the stored original and checks hashes, row identities, mappings and ledger entries. PostgreSQL, protected storage, authentication and authorised case access are not implemented and must precede real-data use.
